# LiveState 🗺️

Интерактивная веб-карта для визуализации территориальных статусов на основе данных **DeepStateMap**.

Проект сделан как один самостоятельный HTML-файл и не требует сборки или backend-сервера.

## ✨ Возможности

- 🌍 Интерактивная карта на **Leaflet**
- 🛰️ Получение актуальных данных из API DeepStateMap
- 🔴 Отображение оккупированных территорий
- 🟣 Отдельное отображение ОРДЛО
- 🔵 Выделение недавно освобождённых территорий
- 🟢 Отображение освобождённых территорий
- 🩶 Отдельный статус Приднестровья
- 📏 Измерение расстояния прямо на карте
- 📐 Измерение площади выделенной области
- 🔄 Автоматическое обновление данных
- 📱 Адаптация интерфейса под мобильные устройства
- 🎨 Интерфейс в стиле Material Design 3
- 🌙 Тёмная карта и тёмная UI-тема

## 🚀 Запуск

### Вариант 1 — GitHub Pages

1. Создайте репозиторий на GitHub.
2. Загрузите `index.html` и этот `README.md`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
5. Сохраните настройки.

После публикации GitHub Pages выдаст адрес сайта.

### Вариант 2 — локально

Просто откройте `index.html` в браузере.

Для нормальной работы загрузки данных через `fetch` лучше использовать локальный HTTP-сервер, например:

```bash
python3 -m http.server 8000
```

После этого откройте:

```text
http://localhost:8000
```

## 📡 Источник данных

Приложение получает данные карты из:

```text
https://deepstatemap.live/api/history/last
```

Данные используются для построения GeoJSON-слоя и определения статуса территорий.

## 🔄 Обновление

По умолчанию данные автоматически обновляются один раз в сутки.

Если запрос завершился ошибкой, приложение повторяет попытку через 5 минут.

При возвращении вкладки в активное состояние приложение также проверяет, не устарели ли данные.

## 📏 Инструмент измерения

Нажмите кнопку с линейкой в левом верхнем углу.

После этого можно:

1. Кликать по карте и добавлять точки.
2. Смотреть суммарное расстояние.
3. Нажать **«Площадь»**, чтобы замкнуть многоугольник.
4. Получить площадь и периметр.
5. Нажать **«Сбросить»** для очистки.
6. Нажать **«Завершить»** для выхода из режима измерения.

Площадь рассчитывается в квадратных метрах/километрах, расстояние — в метрах/километрах.

## ⚠️ Важное замечание

LiveState является клиентским визуализатором данных.

Статусы на карте зависят от внешнего источника данных и могут изменяться или быть временно недоступны.

**Не используйте карту как единственный источник информации для принятия решений, связанных с безопасностью.**
